# 하얀 달의 닷새 — 바리 팬 비주얼 노벨

「림버스 컴퍼니」의 바리가 나오는 **비영리 팬 제작** 미연시(비주얼 노벨)입니다. 신입 직원이 되어 닷새 동안 바리의 안내를 맡고, 선택에 따라 세 가지 맺음 중 하나를 봅니다.

> Project Moon과 무관한 팬 제작물이며 원작의 모든 권리는 원저작권자에게 있습니다.
> 이야기는 창작이고, 그림은 전부 코드로 그렸습니다. 공식 에셋은 쓰지 않았습니다.

## 실행

빌드가 필요 없습니다. `bari-vn/index.html`을 브라우저로 열면 바로 됩니다. (PC·모바일 모두 지원)

- 대사 넘기기: 대사창 클릭/탭, 또는 `Space` · `Enter`
- 진행 상황은 자동 저장되어 첫 화면의 **이어하기**로 이어집니다.
- GitHub Pages가 켜져 있으면 main에 합쳐질 때 `…/bari-vn/` 주소로 함께 올라갑니다.

## 고치는 곳

- **이야기**: `index.html` 안의 `STORY` 배열. 한 줄이 대사 하나입니다. 표기법은 배열 바로 위 주석 참고.
- **맺음 조건**: `ROUTE_A`, `ROUTE_B` (호감 합계 기준, 최대 15).
- **이미지 교체**: `assets/README.md` 참고. 파일만 넣으면 됩니다.
- **아티팩트용 한 장 묶음**: `node bari-vn/build-artifact.mjs` → `bari-vn/dist/artifact.html`
