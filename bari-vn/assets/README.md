# 이미지 넣는 곳

이 폴더에 아래 이름으로 파일을 넣으면 코드로 그린 그림 대신 그 이미지가 나옵니다. 없는 파일은 기본 그림으로 대신합니다.

| 파일 이름 | 쓰이는 곳 | 권장 |
|---|---|---|
| `bari.png` | 바리 기본 스탠딩 (표정별 파일이 없을 때 전부 이걸로) | 배경이 투명한 PNG, 세로로 긴 비율(4:7 안팎), 높이 1400px 이상 |
| `bari_normal.png` `bari_smile.png` `bari_happy.png` `bari_smug.png` `bari_serious.png` `bari_surprised.png` `bari_shy.png` `bari_sad.png` | 표정별 스탠딩 | 위와 같은 크기·위치로 맞추기 |
| `bg_office.jpg` `bg_bookshop.jpg` `bg_alley.jpg` `bg_river.jpg` `bg_rooftop.jpg` (`.png`도 가능) | 배경 | 가로 16:9, 1600×900 이상 |

공식 일러스트나 다른 사람의 팬아트는 저작권자 허락 없이 공개 저장소에 올리지 마세요. 직접 그렸거나 사용 허락을 받은 이미지만 넣는 것을 권합니다.
