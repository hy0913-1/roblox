# King Legacy 서펀트 자동 사냥 매크로

화면을 보고 키보드/마우스만 누르는 매크로입니다. 게임 클라이언트나 메모리는 건드리지 않습니다.

```
나침반 확인 ──서펀트 없음──> 10초 뒤 다시 확인
     │ 서펀트 있음
     ▼
낚싯대 장착 → 던지기 → 입질 감지 → 감아올리기 ──실패──> 다시 던지기
     │ 보스 체력바 등장
     ▼
무기 장착 → 평타 + 스킬(쿨타임마다) ──체력바 사라짐──> 처치, 처음으로
```

> **주의**: 매크로 사용은 게임 규칙 위반으로 제재될 수 있습니다. 본인 책임으로 사용하세요.

## 설치 (Windows)

```
pip install -r requirements.txt
```

Roblox는 **창 모드 또는 전체 창 모드**로, 해상도와 UI 크기를 고정해 두세요. 바꾸면 다시 설정해야 합니다.

## 1. 화면 인식 설정 (최초 1회)

매크로가 알아봐야 할 표시 3가지를 직접 캡처합니다.

| 이름 | 무엇을 캡처하나 | 언제 캡처하나 |
|---|---|---|
| `serpent` | 나침반에 서펀트가 떴다는 표시 | 서펀트가 떠 있고 나침반을 든 상태 |
| `bite` | 입질이 왔다는 표시 (느낌표, 게이지 등) | 낚시 중 입질 순간 |
| `boss` | 서펀트 체력바의 이름 부분 | 서펀트와 전투 중 |

```
python calibrate.py serpent
python calibrate.py bite
python calibrate.py boss
```

실행하면 5초 뒤 화면이 캡처됩니다. 캡처된 화면에서

1. **찾을 대상만** 딱 맞게 드래그 → Enter
2. 대상이 **나타날 수 있는 범위**를 넉넉히 드래그 → Enter

모양이 계속 바뀌어서 이미지로 잡기 어려운 표시는 `--color` 를 붙이면 색으로 인식합니다.
(예: `python calibrate.py bite --color`)

입질 순간처럼 캡처 타이밍을 맞추기 어려우면, 미리 찍어 둔 스크린샷을 전체 화면으로 띄워 놓고 실행해도 됩니다.

## 2. `config.json` 을 내 세팅에 맞추기

| 항목 | 뜻 |
|---|---|
| `compass.key` | 나침반 슬롯 번호. 나침반이 항상 화면에 보이면 `null` |
| `compass.click_to_use` | 나침반을 든 뒤 클릭해야 표시가 나오면 `true` |
| `compass.scan_interval` | 서펀트가 없을 때 다시 확인하는 간격(초) |
| `fishing.rod_key` | 낚싯대 슬롯 번호 |
| `fishing.cast_hold` | 던질 때 클릭을 누르고 있어야 하는 시간(초) |
| `fishing.bite_timeout` | 입질을 기다리는 최대 시간(초) |
| `fishing.reel_seconds` | 입질 후 클릭 연타 시간(초) |
| `fight.weapon_key` | 전투에 쓸 무기/열매 슬롯 번호 |
| `fight.skills` | 쓸 스킬 키와 쿨타임(초) |
| `fight.gone_seconds` | 체력바가 이만큼 안 보이면 처치로 판단 |
| `detectors.*.threshold` | 인식 민감도. 못 찾으면 낮추고(0.7), 잘못 찾으면 높이기(0.9) |

## 3. 실행

```
python macro.py
```

- **F8**: 시작 / 일시정지
- **F9**: 종료

캐릭터를 낚시가 가능한 위치(배 위 등)에 세워 두고 게임 창을 클릭한 뒤 F8을 누르세요.
키 입력이 게임에 안 먹히면 명령 프롬프트를 **관리자 권한**으로 실행하세요.

## 한계

- 매크로는 조준이나 이동을 하지 않습니다. 서펀트가 나오는 방향을 보고 서 있어야 하고, 범위가 넓은 스킬 위주로 넣는 것이 좋습니다.
- 캐릭터가 죽거나 밀려나면 복구하지 못합니다.
- 낚시 미니게임이 "입질 때 클릭/연타" 방식이 아니라면(예: 게이지 맞추기) `fish()` 부분을 고쳐야 합니다.

## 테스트

```
python test_macro.py
```

가짜 화면과 입력으로 동작 순서만 검증합니다. 실제 게임 화면에서는 검증되지 않았습니다.
